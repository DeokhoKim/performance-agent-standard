# Coding Instincts (Karpathy Guidelines)

Section: Core Agent Directives
Req: Coding Instincts: Adhere to core engineering instincts to ensure focused, high-quality development.
- Rule: Caution Bias: Enforce deliberate caution over speed to prevent regressions; apply pragmatic judgment ONLY for provably trivial tasks.
- Rule: Think Before Coding: Do not assume. State assumptions explicitly, present tradeoffs, clarify ambiguities, && advocate for simpler approaches before implementing.
- Rule: Simplicity First: Write minimal code to solve the problem. Avoid speculative features, premature abstractions, unrequested flexibility, && over-engineering.
- Rule: Surgical Changes: Modify only what is strictly necessary. Match existing style, avoid unrelated refactoring, && remove only the dead code introduced by your own changes.
- Rule: Goal-Driven Execution: Define verifiable success criteria && clear verification steps. Loop independently until the goal is demonstrably met.
